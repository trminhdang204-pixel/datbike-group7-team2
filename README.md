# Dat Bike Dealer Request Hub · Group 7 Team 2

Concept prototype for a university innovation project with Dat Bike as the client.
**Not an official Dat Bike product.** All data is sample data, AI suggestions are scripted, and grants are simulated.

**Live demo:** https://dannytruong-lang.github.io/datbike-group7-team2/

## The idea
Dealer quality across Dat Bike's network is uneven. The hub gives HQ one place to set support rules, see each dealer's performance, and approve support requests, while dealers get AI suggestions and fast answers.

- **Dat Bike HQ:** dealer performance dashboard, support policy, approval queue.
- **Dealer:** AI suggestions, new request with a live policy check, request tracking.
- Requests inside policy are approved instantly; bigger ones go to HQ.
- Customer price always stays at MSRP: support is paid to the dealer, never a customer discount.

## Run locally
Open `index.html` in a browser. No build step.
